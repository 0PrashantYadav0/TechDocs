# Authentication & Authorization

Authentication (AuthN) and Authorization (AuthZ) are the bedrock of any secure application. Getting them wrong doesn't just mean a bug; it means a data breach, a PR nightmare, and potentially the end of your company. This module will take you from the basics of identity to advanced distributed authorization patterns.

| 3 | [JWT and Token Security](./jwt-and-token-security.md) | L3 · Intermediate | JWT structure, signing, storage, revocation |
| 4 | [Authorization Patterns](./authorization-patterns.md) | L4 · Advanced | RBAC, ABAC, ReBAC, centralized policies |
