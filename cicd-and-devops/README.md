# CI/CD & DevOps

Welcome to the CI/CD and DevOps module. If you're tired of manually pushing code to production and praying it works, you're in the right place. This module covers the essential practices that separate mature engineering teams from the rest. We'll start with the fundamentals of continuous integration and delivery, explore various deployment strategies to minimize downtime, and finally dive into GitOps and Infrastructure as Code (IaC) to bring sanity to your infrastructure management.
